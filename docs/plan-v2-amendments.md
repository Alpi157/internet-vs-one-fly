# Plan v2 amendments for V2C

Status: DRAFT_REVIEW_REQUIRED. Authorized by the external reviewer relayed in V2C.
The pinned plan-v2.md is unchanged. No protocol is frozen and no H1 or H2 result exists.

A1. Remove looming versus non-looming differences from primary H1 metrics because
encoder selectivity determines that difference. A static stimulus is only an encoder sanity test.

A2. LC4 receives expansion and LPLC2 receives angular size gated by positive expansion.
Looming selectivity is a declared encoder assumption, not an emergent circuit finding.
See D-V2C-ENCODER-01.

A3. A quantity used as a calibration criterion cannot be a primary H1 or H2 outcome.
Primary outcomes use held-out conditions. H1 excludes the standard aimed condition.
H2 excludes the fraction of intervals moving. Publish failures and uncalibratable graphs.

A4. Turn directions are model assumptions supported where possible by quoted primary
sources in turn-directions-v1.json. UNKNOWN types remain circuit seeds but do not
contribute to turn decoding. somaSide does not establish axonal projection side.
