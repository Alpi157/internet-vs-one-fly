How it works

Measured wiring. A simplified model. Results you can check.

What is real here?

The connections come from MaleCNS. The game executes 5,555 neurons and 759,305 directed connections representing 7,397,244 biological contacts. Original body IDs are recoverable; contacts remain separate from executable weights.

Every flash comes from a recorded spike. Replay displays recorded observations. It does not invent activity between frames.

The model

The model passed the calibration registered in prereg-v2. Its selected connection strength is 0.01, from the frozen calibration grid. The selection rule is lowest no-threat mean rate among full-grid passing points, grid-order ties.

Uniform current-based LIF neurons use assumed source transmitter signs. Unknown signs are disabled. Feature-level vision supplies size and expansion. A motor decoder receives only neural activity, with no hand coordinates, distance or future collision information. Walking and escape are neural; body physics and takeoff are simplified. The previous motor command drives the current interval.

The wiring model does not walk on its own. The game adds a declared random drive to the walking neurons (game profile v2.9). Escape comes only from vision through the network. The walking setting was chosen by the author after playtesting four candidates that passed the same safety checks.

Game v2.9 has two hands: a press shorter than 300 ms uses the existing flick (speed 0.04, radius 0.8); a press of 300 ms or longer uses the existing swat (speed 0.025, radius 1.4). Flight lasts 330 ms at 0.018 arena units/ms, a 5.94-unit path. The first 120 ms, direction jitter and wall reflection stay as in v2.8.

Walking design and evidence

Normal rounds preserve neural state. Lab simulations have no walking drive. Changing a lab control explicitly resets both simulations with the same noise seed. Display fading smooths recorded spikes only.

The finding

In this model, measured wiring stays calm at couplings where shuffles that keep each neuron's partner counts and signs saturate.

A stricter preregistered control that also approximately keeps each neuron's total input strength removes most of that gap.

EXPLORATORY: the earlier shuffles flattened the input-strength distribution in T1a (Gini about 0.47, versus 0.65 measured), while N-STRENGTH kept it close (about 0.64). This suggests that, in this model, stability mainly reflects how unevenly input strength is spread across neurons rather than which partners connect. This explanation was not a preregistered mechanism test; the E1 descriptors were preregistered as exploratory.

N-STRENGTH preserves incoming partner counts within sign and contact-count bins; its preservation of total input strength is approximate.

These results apply only to this simplified model, with no claims about living flies. A non-significant result does not establish equivalence. Escape and walking comparisons remain insufficient.

Full family results and limitations

Registered before the runs

The original protocol was publicly timestamped on 2026-10-14, tag prereg-v2. The robustness protocol was publicly timestamped on 2026-10-15, tag prereg-v2.1. Frozen manifests pin code, graph identities, seeds, assumptions and analysis.

Data and verification

The raw-record dataset is 10.5281/zenodo.23409752. Download the checksum-pinned archive, then recompute the published tables without simulating new trials.

uv run python tools/restore_evidence.py --archive /path/to/flybench-raw-records-v2e-v2f.tar.gz
uv run python tools/recompute_v2e.py
uv run python experiments/v2f_analyze.py --out evidence/V2F/results --verify
uv run python experiments/v2f_publish.py --check

The portable original-results check ignores only recorded hardware metadata. See the README for locked dependencies and the frozen verifier's supported host envelope.

Limitations

These results apply only to this simplified model, with no claims about living flies. A non-significant result does not establish equivalence. Escape and walking comparisons remain insufficient.

The strength-preserving comparisons did not replicate the registered stability result. There is no learning, plasticity, realistic biomechanics, human-player study, public verification service or shared score. Scripted bots are engineering evidence, not human usability evidence. Exploratory associations do not establish a mechanism or biological necessity.
